# 笨鸡离线证件照工具

纯前端、单文件、完全离线运行的证件照制作工具。AI 人像分割 + 尺寸裁切 + 底色替换 + 相纸排版，全部打包在一个 HTML 文件里——用浏览器打开即用，无需安装、无需联网、照片不上传任何服务器。

## 特点

- **离线可用**：AI 模型已内嵌，断网也能抠图；
- **隐私优先**：照片全程本地处理，不上传任何服务器；
- **标准尺寸**：覆盖中国证件 / 美国证件 / 国际·签证常用规格；
- **一键导出**：单张导出或相纸排版，支持 300 DPI / 600 DPI。
