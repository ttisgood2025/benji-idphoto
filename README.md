# 笨鸡 · 离线证件照工具

纯前端、单文件、**完全离线**运行的证件照制作工具。AI 人像分割 + 尺寸裁切 + 底色替换 + 相纸排版，全部打包在一个 HTML 文件里——用浏览器打开即用，无需安装、无需联网，照片不上传任何服务器。

当前版本：**v5.22**

## 快速上手

1. **上传照片**：点左侧「上传图片」，或直接把照片拖进画布框。
2. **调整取景**：在画布上拖动移动人物，滚轮或上方滑块缩放，让人物居中于蓝色框内。蓝框外区域导出时会被裁掉，中间实时预览就是最终效果。
3. **选规格与底色**：
   - 区域选「中国证件 / 美国证件 / 国际·签证」，规格选所需尺寸（一寸、二寸、护照、签证等）；
   - 点色块选白 / 蓝 / 红 / 淡蓝 / 粉 / 灰，或点「自定义背景色」任选颜色；
   - 勾选「**替换背景色**」才会启用 AI 抠图换底；发丝边缘有残留可用「边缘扩展」微调。
4. **导出**：
   - 「导出单张」按所选规格输出，可选标准 300 DPI 或高清 600 DPI；
   - 「导出排版图」把多张排进 5 寸 / 6 寸 / A4 相纸，方便送冲印店。

## 特点

- **离线可用**：AI 模型已内嵌，断网也能抠图。
- **隐私优先**：照片全程本地处理，不上传任何服务器。
- **标准尺寸**：覆盖中国证件 / 美国证件 / 国际·签证常用规格。
- **一键导出**：单张导出或相纸排版，支持 300 / 600 DPI。
- **免安装**：单 HTML 文件，双击打开，不写注册表、不联网激活。

## 如何更新

工具页面右上角有「**检查更新**」按钮，点一下即可：

1. 提示「已是最新版本」→ 无需操作；提示「发现新版本」→ 点「确定」。
2. 浏览器自动下载新版 HTML（无需密码、无需解压）；若浏览器没反应，会自动打开下载页，点一下即可。
3. 把新文件覆盖旧文件，用同一个浏览器打开就是新版。建议不要改名、不要挪位置。

检查更新需要联网；日常抠图和导出完全不需要联网。

## 常见问题

| 现象 | 处理 |
|---|---|
| 打开空白或排版乱 | 换 Chrome / Edge / Firefox 新版浏览器 |
| 勾选换底色后提示 AI 失败 | 浏览器需支持 WebGL；关闭后重试，或暂时不换底 |
| 导出图点「下载」没反应 | 右键预览图 →「图片另存为」，或用「复制到剪贴板」 |
| 设置（规格 / 底色）下次打开没了 | 检查是否换了浏览器、用了无痕模式，或把文件挪了位置 |
| 导出的 JPG 文件太小 | 正常。JPEG 压缩效率高，300 DPI 符合冲印行业标准；想更清晰选 600 DPI |
