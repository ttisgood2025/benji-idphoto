# 笨鸡离线证件照工具 · 使用说明

> 一句话：上传照片 → 调整取景 → 选规格/换底色 → 导出。全程在你自己的电脑上完成，照片不上传任何服务器，断网也能用。

---

## 一、它能做什么

- 把一张普通照片，做成符合**标准证件照尺寸**的图片（一寸、二寸、护照、签证等）。
- 自动把人物从原背景里抠出来，换成白 / 蓝 / 红等底色（AI 抠图，已内嵌，无需联网）。
- 一键导出单张，或把多张排进相纸（5 寸 / 6 寸 / A4）方便送冲印店。

**隐私**：所有处理都在浏览器本地完成，照片不会上传到任何服务器。

---

## 二、四步上手

1. **上传照片**
   - 点左侧「上传图片」，或把照片直接拖进左侧画布框。
2. **调整取景**
   - 在画布上**拖动**移动人物，**滚轮**或上方滑块缩放，让人物居中于蓝色框内。
   - 蓝框外区域导出时会被裁掉；中间实时预览就是最终效果。
3. **选规格与底色**
   - 「区域」选：**中国证件 / 美国证件 / 国际·签证**。
   - 「规格」选你要的尺寸（一寸、二寸、护照、签证…）。
   - 换底色：点色块选 白 / 蓝 / 红 / 淡蓝 / 粉 / 灰，或点「自定义背景色」任选颜色。
   - 勾选「**替换背景色**」才会启用 AI 抠图换底；发丝边缘有残留可用「边缘扩展」微调。
4. **导出**
   - **导出单张**：按所选规格输出。分辨率可选：
     - 标准 300 DPI（冲印行业标准，文件小）；
     - 高清 600 DPI（像素翻倍，细节更清晰）。
   - **导出排版图**：同一张排进相纸，中栏下方有预览，方便冲印。

---

## 三、关于导出文件大小

导出的 JPG 体积较小是**正常的**——JPEG 压缩效率高，像素严格符合 300 DPI 行业标准，冲印清晰。
追求更清晰可选「高清 600 DPI」，文件会大一些。

---

## 四、如何更新工具

页面**右上角**（版本号旁边）有「**检查更新**」按钮。更新只需三步：

1. **点「检查更新」**
   - 提示「已是最新版本」→ 无需操作；
   - 提示「发现新版本 vX.X」→ 点「确定」。
2. **自动下载新文件**
   - 浏览器会自动下载 `笨鸡离线证件照工具.html`（无需密码、无需解压）；
   - 若浏览器没反应，会自动打开下载页面，在页面上点一下即可下载。
3. **覆盖旧文件**
   - 把下载好的新文件，放到你原来存放的位置，**覆盖**旧文件，用同一个浏览器打开即是新版；
   - 建议**不要改名、不要挪到别的文件夹**。

> 检查更新需要联网；日常抠图、导出完全不需要联网。

---

## 五、用不了 / 不对劲怎么办

| 现象 | 处理 |
|---|---|
| 打开是空白或排版乱 | 换 Chrome / Edge / Firefox 新版浏览器 |
| 勾选换底色后提示 AI 失败 | 浏览器需支持 WebGL；关闭后重试，或暂时不换底 |
| 导出的图点「下载」没反应 | 右键预览图 →「图片另存为」，或用「复制到剪贴板」粘贴 |
| 设置（规格/底色）下次打开没了 | 是否换了浏览器、是否用了无痕模式、是否把文件挪了位置 |

---

## 六、兼容性

- 推荐：Chrome / Edge / Firefox 较新版本。
- 需要支持 WebGL（AI 抠图依赖）。
- 完全离线可用，无需联网；AI 模型已打包在本文件内。
